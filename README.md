# Age-Of-Empires-III---Knights-And-Barbarians Remastered
A medieval total overhaul mod for the classic "Age Of Empires III - The Asian Dynasties" 
This project aims to remaster the K&B mod that got abandoned by the old K&B team around 2013 and development stopped. The goal is to add 5 more civs,
modernize the UI, add new units, balance the civilizations, refocus the mod on the mediterranean and bring to life the Crusades era in AoE III.
